# DBML Studio UI 设计规范

> 面向本地优先数据库建模工具的界面规范。目标是让「写 DBML」与「看关系图」在同一屏内形成低干扰、可预测的工作闭环。

| 项目 | 内容 |
|---|---|
| 规范版本 | 1.0 |
| 发布日期 | 2026-10-22 |
| 适用版本 | DBML Studio 0.1.0（macOS arm64） |
| 状态 | 现行 |
| 视觉基准 | `docs/ui-mockup.html`（工作区）；欢迎页、标签栏以本规范 + 当前实现为准 |
| Token 来源 | `src/styles.css` |

---

## 0. 文档定位

### 0.1 权威来源

按以下顺序判定冲突：

1. 产品与安全约束（完全离线、DBML 单一数据源、不执行导入 SQL）
2. 本设计规范
3. `docs/ui-mockup.html` 视觉稿
4. 局部实现代码

具体的数值与颜色以 `src/styles.css` 中的自定义属性为单一来源。规范记录的是**设计意图与验收标准**，不是对 CSS 的逐行复述。

### 0.2 规范用语

| 用语 | 含义 |
|---|---|
| 必须 / 禁止 | 硬性要求，评审时可直接判定不通过 |
| 应当 | 默认遵循；偏离时需说明理由 |
| 可以 | 允许的扩展空间 |

### 0.3 适用范围

- 覆盖：窗口框架、标题栏、标签栏、工作区、欢迎页、属性面板、设置、快捷键、导出、弹窗、反馈与空状态。
- 不覆盖：安装包、系统菜单、Dock 图标等原生外壳；这些遵循 macOS 平台规范。

## 1. 设计原则

| 原则 | 设计含义 | 验收标准 |
|---|---|---|
| **本地可信** | 所有视觉与文案都应强化「文件在本地、无账号、无网络」的确定感 | 界面不出现在线状态、账号入口、云端同步、遥测提示；断网不影响任何功能 |
| **文本为源** | DBML 是唯一数据源，画布与属性面板都是它的视图 | 任何画布操作最终落到 DBML 文本；语法错误时画布保留上次有效版本并明确提示 |
| **内容优先** | 框架安静，数据突出；不使用大面积品牌色与装饰性插画 | 中性色承担 90% 以上面积，强调色只用于选择、焦点和主操作 |
| **克制反馈** | 用位置、层级和少量语义色表达状态，不用庆祝动画 | Toast 自动消失；状态变化有文字或图标，不只依赖颜色 |
| **键盘可达** | 高频操作无需离开键盘 | 文件、视图、画布、弹窗均有键盘路径；焦点可见 |
| **明暗等价** | 深浅主题拥有同一信息层级与功能完整度 | 两套主题逐一走查，不允许某一主题缺失状态或对比失衡 |
| **桌面密度** | 这是高密度建模工具，不是营销网站 | 正文 11.5px 起；9–10.5px 仅用于元数据；控件高度 24–40px |

## 2. 品牌与 Logo

### 2.1 名称

- 产品名固定为 **DBML Studio**，`DBML` 全大写，中间保留一个空格。
- 标题栏品牌区可带「本地」胶囊；其他位置不重复该胶囊。
- 英文标语 `Local-first database modeling` 仅用于欢迎页标题栏中央；中文场景使用「本地优先 · DBML 单一数据源」。

### 2.2 图形构成

Logo 由三个圆角矩形节点与一条连接线组成，表达「表结构 + 关系」：

| 元素 | 规格 |
|---|---|
| 画布 | `viewBox="0 0 20 20"`，无填充（`fill="none"`） |
| 节点 | 3 个 `6.2 × 4.6` 圆角矩形，圆角 `1.2` |
| 节点位置 | 左上 `(2.2, 2.6)`、右上 `(11.6, 2.6)`、右下 `(11.6, 12.8)` |
| 连接线 | `M8.4 4.9h3.2M14.7 7.2v5.6M5.3 7.2v5.6a2 2 0 0 0 2 2h4.3` |
| 描边 | 白色，`stroke-width="1.25"`，圆角端点与转角 |
| 图形占比 | 容器边长的 **62%**，四周留白均匀 |
| 容器背景 | `linear-gradient(145deg, #6d6bf2, #4338ca)` |
| 容器阴影 | `0 4px 10px rgba(79,70,229,.3), inset 0 1px 0 rgba(255,255,255,.35)` |

### 2.3 尺寸

| 场景 | 容器 | 圆角 | 阴影 |
|---|---|---|---|
| 标题栏 | 28px | 8px | 默认 Logo 阴影 |
| 欢迎页品牌区 | 44px | 12px | `0 10px 24px rgba(79,70,229,.22)` |
| 启动页 | 54px | 15px | `0 12px 30px rgba(79,70,229,.3)` + 1.7s 上下浮动 |
| 导出预览等小尺寸 | 22px | 8px | 默认 Logo 阴影 |

- 最小使用尺寸为 22px，禁止继续缩小。
- Logo 与文字并排时，间距 8px（标题栏）或 12px（欢迎页）。
- 品牌标志使用 `BrandMark` 组件，禁止在业务页面重绘。

### 2.4 禁止事项

- 禁止拉伸、旋转、压扁或改变 3 个节点的相对位置。
- 禁止替换为纯色背景、改变渐变方向、反转颜色或添加描边。
- 禁止在容器内添加文字、数字、表情或额外图标。
- 禁止在 Logo 上叠加投影以外的特效。
- 禁止把图形单独作为 favicon 之外的无容器标识使用。

### 3.1 用色模型

所有界面色必须来自语义 Token。允许的硬编码颜色仅限：

- Logo 渐变；
- macOS 红黄绿交通灯；
- 设置中的主题预览缩略图；
- Monaco 编辑器主题色（由编辑器 API 管理）。

### 3.4 数据色板

数据色不是主题色，只用于标识具体的表或关系。

**表头色（9 色）**

`#4f8ff7`、`#6366f1`、`#f59e0b`、`#10b981`、`#ec4899`、`#8b5cf6`、`#0ea5e9`、`#f97316`、`#94a3b8`

**关系色（7 色）**

`#4f46e5`、`#0ea5e9`、`#10b981`、`#f59e0b`、`#ef4444`、`#8b5cf6`、`#64748b`

使用规则：

- 表头使用数据色 **7.5%（浅色）/ 16%（深色）** 的染色，加上顶部 3px 实色条；数据色不直接作为长段文字色。
- 关系线默认使用 `--edge`；选择数据色后用于线、端点和基数标签。
- 未选中关系降低对比，不作为背景大面积铺色。
- 数据色只是辅助识别，必须同时有表名、字段名或关系文本，不能作为唯一信息载体。

### 3.6 对比度与使用边界

基于 sRGB 相对亮度计算（WCAG 2.1）：

| 前景 / 背景 | 浅色 | 深色 | 结论 |
|---|---:|---:|---|
| `text` / `panel` | 15.93:1 | 14.28:1 | 通过 AAA |
| `text-2` / `panel` | 8.11:1 | 9.22:1 | 通过 AAA |
| `muted` / `panel` | 3.77:1 | 5.86:1 | 浅色不满足普通文本 AA |
| `faint` / `panel` | 2.34:1 | 3.43:1 | 浅色不满足任何文本 AA |
| `accent` / `panel` | 6.29:1 | 5.85:1 | 通过 AA |
| `accent` / `accent-soft` | 5.55:1 | 4.98:1 | 通过 AA |
| `ok` / `panel` | 3.39:1 | 8.87:1 | 浅色仅适合图标 / 大字号 |
| `warning` / `warning-bg` | 3.38:1 | 7.36:1 | 浅色仅适合短警告 + 图标 |
| `danger` / `danger-soft` | 3.94:1 | 6.01:1 | 浅色仅适合短提示 + 图标 |
| `border-strong` / `panel` | 1.39:1 | 1.65:1 | 仅装饰性边界，不承担信息 |
| `edge` / `canvas` | 2.39:1 | 3.29:1 | 浅色关系线对比偏低 |

落地规则：

1. 普通正文必须 ≥ 4.5:1；大字号（≥ 18.66px 粗体或 ≥ 24px）可 ≥ 3:1；非文本 UI 边界 ≥ 3:1。
2. `--faint` 只能用于非关键、可丢失的装饰信息（分隔符、微标签、脚注），不得用于状态、错误、操作说明。
3. `--muted` 可用于辅助说明，但浅色主题下不应用于大段正文。
4. 语义色（ok / warning / danger）必须同时搭配图标或文字，不能只依赖颜色。
5. 输入框、卡片等控件的可辨识性不能只依赖 `--border`；需要背景差、标签或焦点环共同承担。

> 已知现状：浅色主题大量 8–9px 标签使用 `--faint`，属于可访问性欠账，详见附录 A。

## 4. 字体与排版

### 4.1 字体族

### 4.3 排版规则

- 可用字重：400、520、560、570、580、620、650、660、680、700、720。通过 20 级字重微调层级，不额外增加字号。
- 阅读型正文不小于 11.5px；9–10.5px 只用于元数据、计数与高密度控件。
- 中文正文行高 1.5–1.75；标题 1.12–1.3。
- 负字距只用于较大字号或拉丁字标，中文正文不设负字距。
- 所有数字对齐场景使用 `font-variant-numeric: tabular-nums`：缩放比例、行列号、计数、时间。
- 标题、按钮、标签使用单行截断；完整内容通过 `title` 或属性面板呈现。
- 代码、类型名、路径、快捷键组合使用等宽字体。
- 中文不使用全大写；仅英文分组标题使用 `text-transform: uppercase`。

## 5. 空间、圆角、阴影与层级

### 5.1 间距

以 4px 为主节奏，允许 2px 半阶用于高密度控件：

| 场景 | 建议值 |
|---|---:|
| 图标与文字 | 4–8px |
| 控件内部水平留白 | 7–11px |
| 按钮组 / 图标组间隔 | 1–2px |
| 表单项间隔 | 7–9px |
| 面板内边距 | 12–14px |
| Modal 内容内边距 | 18–19px |
| 区块间距 | 20–28px |
| 欢迎页内容间距 | 34–54px |
| 画布浮层外边距 | 14px |

7、9、11、13px 是既有组件的光学校正值，可继续使用，但不得成为新的通用阶梯。

### 5.2 圆角

| 值 | 用途 |
|---:|---|
| 3–5px | 微徽标、快捷键盘、色块、标签关闭 |
| 6–7px | 小按钮、输入框、侧栏条目、工具按钮 |
| 8–9px | 常规按钮、搜索框、Toast、右键菜单、Logo（28px） |
| 10–12px | 表格卡片、欢迎页面板、设置分组、Logo（44px） |
| 14px | Modal |
| 15px | 启动页 Logo（54px） |
| 99px | 胶囊、开关、滑块 |

### 5.3 阴影

- 低层级卡片使用 `--card-shadow`；浮层使用 `--panel-shadow`；Modal 不额外叠加多层阴影。
- 悬停只允许一次阴影加深，不叠加位移或缩放。
- 深色主题使用更高不透明度，因为环境光更弱。
- 选中态优先使用 accent 描边 + 2px 外环，不用大阴影表达。

### 5.4 层级

| z-index | 层 |
|---:|---|
| 8 | 画布状态徽标 |
| 9 | 画布顶部警告、底部工具栏、忙碌提示 |
| 12 | 属性面板 |
| 20 | 标签栏、状态栏 |
| 30 | 标题栏 |
| 100 | Modal 遮罩 |
| 150 | 右键菜单 |
| 200 | Toast |

不得用任意大数抢占层级；新增浮层先复用现有层级语义。

## 6. 布局

### 6.1 窗口

| 项 | 规格 |

## 8. 状态与反馈

### 8.1 解析状态

| 状态 | 画布 | 状态栏 | 编辑器 |
|---|---|---|---|
| 解析中 | 保持上次结果 | `解析中` + 旋转 | 可继续输入 |
| 语法正确 | 实时更新 | `语法正确` | 正常诊断 |
| 语法错误 | 保留上次有效版本 | 红色错误 + 解释 | 标记错误、打开 Problems |
| 空文档 | 空状态图形 | 0 表 0 关系 | 空编辑器 |

### 8.2 保存状态

| 状态 | 触发 | 表现 |
|---|---|---|
| 未保存 | 内容变更 | 标签页 6px 圆点 + 状态栏 warning「未保存」 |
| 保存中 | 手动/自动保存 | 状态栏「保存中…」，按钮禁用 |
| 已保存 | 写盘成功 | 圆点消失，状态栏「已保存」或「已保存 14:32」 |
| 保存失败 | 写盘失败 | Toast error + 状态栏错误；编辑内容与快照保留 |
| 自动保存 | 停止编辑约 1.4s | 仅在语法正确且已有路径时写盘 |

### 8.3 多文档状态

- 每个标签独立维护 `dirty`；非活动标签的修改在切换时写入内存快照。
- 关闭标签、返回欢迎页、关闭窗口均需检查所有标签的未保存状态。
- 未保存弹窗：
  - 单文档标题「保存修改？」，多文档「保存多个文档？」。
  - 副标题说明未保存数量与即将发生的动作。
  - 操作：取消 / 放弃修改 / 保存并继续（多文档为「全部保存并继续」）。
  - 放弃修改会清理恢复快照，文案必须明确。
- 切换标签会重挂载编辑器；**不保留每个标签的撤销栈**，属于已知限制。

### 8.4 选择与联动

- 选中表：显示属性面板，画布相关表和关系高亮，其余弱化。
- 选中关系：两端表高亮，关系线加粗为 accent，属性面板显示关系详情。
- 编辑器光标所在表：轻量外环提示，不打开属性面板。
- 点击画布空白：清除选择并收起右键菜单。
- `Esc`：关闭弹窗 → 关闭右键菜单 → 取消选择的优先级从高到低。

### 8.5 空状态

| 场景 | 标题 | 说明 | 操作 |
|---|---|---|---|
| 画布无表 | 从第一张表开始 | 在左侧编写 DBML，画布会实时呈现 | 新建第一张表 |
| 语法错误且无有效版本 | 暂时无法绘制 | 修复语法错误后自动恢复 | 查看问题列表 |
| 最近文件为空 | 还没有最近打开的文件 | 打开一个 .dbml 文件，它会出现在这里 | — |
| Problems 为空 | 语法检查通过 | 错误与警告会实时显示 | — |
| 搜索无结果 | 没有匹配的表或字段 | — | — |

### 8.6 删除与危险操作

- 删除表、关系、字段必须二次确认；确认框标题说明对象，正文说明会改写 DBML。
- 危险确认使用 danger 图标、danger 主按钮。
- 删除后若相关选中项失效，清空选择并收起属性面板。
- 不提供无确认的批量删除。

### 8.7 恢复与启动

- 启动页：54px Logo + 1.7s 呼吸动画 + 11px 文案；不阻塞超过必要时间。
- 恢复快照：编辑后 1s 节流写入应用数据目录；每个文档最多 5 份、保留 7 天。
- 欢迎页检测到快照时显示恢复横幅；恢复操作必须在明确选择后进行。

### 9.2 快捷键作用域

- 单键快捷键（`F`、`L`、`?`、`Delete`）仅在焦点不在输入框、文本域、下拉框、可编辑区域或 Monaco 编辑器时生效。
- 带修饰键的快捷键优先于 Monaco；但 `⌘Z` 在编辑器内交给 Monaco，避免破坏文本撤销栈。
- 弹窗打开时，底层快捷键不应触发；`Esc` 只关闭最上层浮层。当前仅对 `Esc` 做了统一处理，其余快捷键尚未按浮层作用域拦截，见附录 A。
- 快捷键面板为只读说明，当前版本不支持自定义键位。

### 9.3 标签与文件操作

- `⌘N` / `⌘O` 总是新建标签，不替换当前标签。
- `⌘W` 关闭当前标签；若只有一个标签，关闭后回到欢迎页。
- `⇧⌘W` 关闭窗口；关闭窗口前检查所有文档的未保存状态。
- 打开同一路径的文件时激活已有标签，不重复打开。
- 打开失败（缺失、编码错误、权限）使用 error Toast，并保留欢迎页/当前文档。

| 操作 | 结果 |
|---|---|
| 拖拽表头 | 移动表；释放后写入布局 |
| 拖拽字段锚点 | 创建关系；释放到合法字段后插入 `Ref` |
| 拖拽空白 | 平移画布 |
| 滚轮 / 触控板 | 缩放画布 |
| `Shift` + 拖拽空白 | 框选 |
| 单击表 / 边 | 选中并打开属性面板 |
| 双击表 / 边 | 选中并在编辑器中定位 |
| 右键表 / 边 / 空白 | 打开对应上下文菜单 |
| 单击空白 | 取消选择 |

- 非法连接（同一字段自连）立即取消，不插入文本。
- 从字段拖拽时显示 accent 预览线；目标字段须有视觉反馈。
- 自动布局期间显示「正在计算布局…」，布局完成后保持选中对象。

### 9.5 焦点与键盘

- 所有按钮、标签、输入框、菜单项必须可通过 `Tab` 到达。
- 可见焦点环：2px accent、偏移 2px；输入框使用 3px 10% 光晕。
- 标签栏使用 roving tabindex；活动标签可聚焦。
- 菜单项支持 `Enter` / `Space` 激活。
- Modal 当前缺少完整的焦点陷阱与初始焦点管理，见附录 A。

## 10. 动效

| 场景 | 时长 | 缓动 / 说明 |
|---|---:|---|
| 颜色、背景、边框悬停 | 0.15s | ease |
| 按钮按下 | 0.1s | 位移 1px |
| 标签页切换 | 0s | 即时，不滑动 |
| Modal 入场 | 0.18s | `cubic-bezier(.2,.85,.35,1)`，淡入 + 8px 上移 |
| Modal 遮罩 | 0.16s | 淡入 |
| Toast 入场 | 0.2s | `cubic-bezier(.2,.85,.35,1)`，6px 上移 |
| 右键菜单 | 0.12s | 淡入 + 3px 下移 |
| 属性面板 | 0.16s | 淡入 + 6px 右移 + 0.99 缩放 |
| 开关 | 0.16s | `cubic-bezier(.2,.8,.3,1)` |
| 关系线高亮 | 0.15s | 颜色/线宽 |

- 不使用弹跳、闪光、粒子或庆祝式动效。

## 11. 无障碍

### 11.1 必须满足

- 所有图标按钮有 `aria-label` 或可见文字；装饰性图标 `aria-hidden`。
- 焦点可见且不被背景吞没；禁止 `outline: none` 而无替代。
- 状态不能只靠颜色：错误、警告、成功都必须有图标或文字。
- 颜色对比度目标：正文 ≥4.5:1，大文本 ≥3:1，UI 边界 ≥3:1。
- 支持系统减少动效。
- 所有危险操作可键盘取消，且默认焦点不在破坏性按钮上。
- 中文文案使用完整句子，避免只有术语的按钮。

### 11.2 现状与改进项

| 项 | 现状 | 建议 |
|---|---|---|
| 小字号低对比 | 大量 8–9px 使用 `--faint`，浅色主题对比不足 | 关键状态改用 `--muted`/`--text-2`；`--faint` 仅保留装饰 |
| 标签页关闭按钮 | 视觉 18 × 18px | 增加透明命中区至 ≥24 × 24px，视觉尺寸不变 |
| 属性面板色块 | 17px 色块 | 命中区至少 24px；提供颜色名称 |
| 表格底部新增字段 | 16px 按钮 | 扩大命中区，或提供整行可点击区域 |
| Modal 焦点 | 未实现焦点陷阱和初始焦点 | 打开时聚焦标题/首个控件，关闭后归还触发元素 |
| 状态栏字号 | 9px | 关键保存状态与语法状态可提升至 10–11px |
| 关系线对比 | 浅色 `--edge` 对画布约 2.39:1 | 选中/悬停提高对比；默认线可使用略深的中性色 |

设计规范将上述项视为**已知欠账**，新功能不得继续扩大这些问题。

## 12. 文案规范

### 12.1 语言与语气

- 界面主语言为简体中文；DBML、SQL、PNG、schema、sidecar 等术语保留英文原文。
- 语气直接、专业、克制；不使用感叹号、拟人化卖萌或营销口号。
- 错误文案结构：**发生了什么 + 影响 + 下一步**。
  - 示例：「保存失败，当前编辑仍保留在内存中。请检查文件权限后重试。」
- 破坏性文案明确说明后果，不使用模糊的「确定吗？」。
- 省略号统一使用 `…`，不使用 `...`。

| 路径 | 等宽字体，尾部省略 | `/Users/chunle/Documents/shop.dbml` |

### 12.3 固定文案

## 13. 实现约定

### 13.1 Token 与样式

- 颜色、阴影、字体、圆角优先使用 `src/styles.css` 的自定义属性。
- 主题差异只通过 `[data-theme="dark"]` 覆盖 Token；组件内部不写 `if (dark)` 样式。
- 半透明染色使用 `color-mix(in srgb, var(--token) N%, transparent)`，不新增近似色。
- 所有新组件必须同时检查浅色与深色。
- 新增 `z-index` 前先复用现有层级语义。

### 13.2 图标

- 统一使用 Lucide 图标，线性风格，默认描边。
- 尺寸：9–11px 行内元数据，12–14px 控件，15–17px Modal/主操作，18px+ 空状态。
- 图标与文字间距 4–7px；纯图标按钮必须有可读标签。
- 不使用多套图标混搭，不使用 emoji 代替图标。

### 13.3 品牌

- Logo 统一通过 `src/components/BrandMark.tsx` 渲染。
- 修改 Logo 时必须同步本规范 §2；禁止只改某一处尺寸或圆角。
- 欢迎页 Logo 的文字必须置于 `.welcome-brand-copy` 容器，避免通用 flex 规则覆盖 `.logo` 的居中网格。

### 13.4 响应式检查

每次 UI 变更至少检查：

- 1440 × 900（默认）
- 1180 × 800（窄桌面）
- 1000 × 640（Tauri 最小尺寸）
- 760px 宽（浏览器预览）

检查项：无横向滚动、无控件重叠、按钮文字不换行、浮层不超出视口、属性面板在 ≤1020px 正确隐藏。

### 13.5 设计交付

- 新组件先在本规范中找到对应章节；没有则新增章节并说明与现有模式的关系。
- 视觉变更需附浅色与深色截图。
- 涉及交互的变更需说明键盘路径与空状态。
- 变更 Token 或核心尺寸时同步更新本文件与 `docs/ui-mockup.html`（如相关）。

## 附录 A：已知偏差与后续改进

| # | 项目 | 当前实现 | 影响 | 建议 |
|---:|---|---|---|---|
| 1 | 浅色低对比元数据 | `--muted` 3.77:1、`--faint` 2.34:1，大量 8–9px 使用 | 可读性弱，未达 WCAG AA | 关键信息提升颜色或字号；`--faint` 仅装饰 |
| 2 | 语义色对比 | 浅色 warning 3.38:1、danger 3.94:1、ok 3.39:1 | 小字号语义文本偏弱 | 仅用于图标/短标签；必要时加深语义色或加底色 |
| 3 | 标签页关闭命中区 | 视觉 18 × 18px | 点击容错低 | 增加透明命中区至 ≥24px |
| 4 | Modal 焦点管理 | 有 `role="dialog"`、`Esc`、遮罩关闭，无焦点陷阱 | 键盘/读屏体验不完整 | 增加初始焦点、焦点陷阱、关闭后归还焦点 |
| 5 | 每标签撤销历史 | 切换标签重挂载编辑器 | 撤销栈不跨标签保留 | 在文档快照中保存编辑器模型或历史 |
| 6 | 状态栏字号 | 9px，多数字段为 `--faint` | 关键状态偏小偏淡 | 保存/语法状态提升至 10–11px 并使用 `--muted` |
| 7 | 关系线对比 | 浅色默认边对画布约 2.39:1 | 弱视用户辨识困难 | 悬停/选中增强；默认边略加深 |
| 8 | 快捷键自定义 | 固定键位，只读面板 | 无法适配用户习惯 | P1 引入可配置键位与冲突检测 |
| 9 | 外部修改检测 | 当前版本未实现（P1） | 多工具并行编辑可能覆盖 | 窗口聚焦时比较 mtime，提示重载/覆盖 |
| 10 | 浮层快捷键作用域 | 除 `Esc` 外，全局快捷键未按 Modal 阻断 | 弹窗打开时仍可能触发保存/切换视图 | 在全局键盘处理中先判断浮层状态 |

> 这些偏差不是放松规范的理由。新功能应在现有欠账之上做增量改进，而不是复制问题。
